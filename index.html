How to use this tool

Finding a path: Select two or more elements (points) using the layer + element pickers, then click Find Path. The tool searches the ArchiMate 3.1 Appendix B relationship tables for valid routes.


Ordered vs Connect set:
Ordered respects your Start → Via → End order (use this when direction/order matters).
Connect set treats your selections as an unordered set and automatically chooses an order that minimises total path cost, then displays the resulting single chain.


Direct vs Derived:
Direct relationships appear in uppercase in Appendix B — they are explicitly defined between two element types.
Derived relationships appear in lowercase — they are valid by §5.7 derivation rules (e.g. if A realises B and B realises C, A derivedly realises C). Enabling derived reveals many more cross-layer paths.


Compact vs Swimlanes:
Compact shows all elements in a single row from left to right.
Swimlanes places each element in its ArchiMate layer band (Technology, Application, Business…) so cross-layer paths are immediately visible.


Adding points: Use + Add intermediate element to add more points to connect. In Ordered mode this forces the route through that point; in Connect set mode it’s simply another point to include.


No path found? Try: enabling + Derived, or adding a point in an intermediate layer.


Learn an element: After a path is shown, click any element shape in the diagram or a name chip in the explanation to open the spec-style definition. You can also jump from there to the spec excerpts below.
